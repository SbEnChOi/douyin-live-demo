# Douyin Live Studio

도우인 느낌의 중국어 라이브 방송 화면을 촬영하기 위한 독립형 웹 시연 도구입니다. 실제 도우인 서비스 연결, 방송 송출, 상품 주문, 결제는 하지 않습니다.

## 사용

`dist/index.html`을 브라우저에서 열면 바로 실행됩니다. 영상·사진을 선택하거나 카메라를 켜서 배경을 설정하세요. 자동 중국어 댓글, 수동 댓글, 팔로우, 하트, 장미 선물 효과를 사용할 수 있습니다. 방송 이름, 시청자 수, 좋아요 수와 댓글 속도를 조절할 수 있습니다. 직접 작성한 댓글은 한 줄에 하나씩 입력 후 적용하세요.

`촬영 모드 시작` 또는 `F`를 누르면 9:16 방송 화면만 표시합니다. 마우스를 움직이거나 화면을 터치하면 돌아가기 버튼이 잠시 나타납니다. `Esc`로 설정 화면으로 돌아갑니다. 운영체제나 브라우저의 화면 녹화 기능으로 촬영하세요. 이 앱이 직접 녹화 파일을 생성하지는 않습니다.

카메라는 HTTPS 배포 주소 또는 localhost에서 사용하세요. 카메라 권한은 직접 허용해야 합니다. 파일은 브라우저 메모리에서만 사용하고 서버로 업로드하지 않습니다. 재생 가능한 코덱은 브라우저에 따라 다릅니다. MP4(H.264) 또는 WebM을 권장합니다. 설정과 업로드 파일은 페이지를 새로 열면 초기화됩니다.

## 추가 효과

반응 효과 3종: 네온 폭죽(1), 황금 불꽃(2), 무지개 파티(3). 설정 버튼 또는 방송 화면의 선물 메뉴에서도 실행할 수 있습니다. 약 6초 후 자동으로 사라집니다. 다른 효과를 누르면 새 효과로 교체합니다.

얼굴 필터 3종: 왕눈이 토끼(4), 꿀꿀 돼지코(5), 콧수염 아저씨(6). 얼굴이 있는 사진, 영상 또는 카메라를 사용하면 얼굴 위치를 추적합니다. 배경이 없을 때는 캐릭터로 필터를 미리 보여줍니다. 같은 필터를 다시 누르면 해제됩니다. 0을 누르면 반응 효과와 얼굴 필터를 모두 끕니다. 글을 입력하는 동안 단축키는 작동하지 않습니다.

얼굴 추적은 Google MediaPipe Tasks Vision 1.1.0과 BlazeFace short-range 모델을 사용하며, 라이브러리와 모델을 사이트에 포함했습니다. 사진이나 영상 프레임은 브라우저의 Worker에서 처리하고 서버에 보내지 않습니다. 추적이 지원되지 않는 브라우저에서는 수동 위치 조절을 사용하세요. 여러 얼굴 중 가장 큰 얼굴 하나에 적용됩니다. 얼굴이 화면에서 사라지면 필터를 숨깁니다. 얼굴을 크게 움직이면 일시적으로 추적이 끊길 수 있습니다.

라이브러리: https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector/web_js

## 드립 치는 시청자

기본으로 시연형 시청자 댓글봇이 켜져 있습니다. 자동 댓글은 기본 약 6초 간격이며, 2–15초로 바꿀 수 있습니다. 실제 사람의 댓글 간격처럼 조금씩 달라집니다. 중국어 인터넷 드립이 기본이며, 한국어 인터넷 말투가 섞이는 비율은 기본 12%, 조절 범위는 0–40%입니다.

방송 화면의 채팅창에 질문하면 약 2–4초 후 중국어 농담으로 답합니다. 가끔 다른 시청자가 후속 댓글을 붙입니다. 입력 중 표시가 나오며, 여러 질문은 순서대로 답하고 기존 자동 댓글은 답변하는 동안 잠시 기다립니다. 자동 댓글을 일시정지해도 질문 답변은 계속합니다. 시청자 반응 자체를 끄면 답변 대기열도 취소되고 원래의 샘플 댓글로 돌아갑니다.

“내 이름은 승빈” 뒤 “내 이름 기억나?”처럼 이름을 기억하며, 필터 추천 뒤 “왜?”나 “더” 같은 후속 메시지도 이어갑니다. 필터·폭죽과 카메라 얼굴의 등장·이동·가까워짐에 관련된 드립을 붙입니다. 얼굴 관찰도 브라우저에서만 처리합니다. 새로 시작하면 대화 기억과 대기열을 지웁니다.

외부 언어모델을 호출하지 않는 규칙·문구 기반 시연용 댓글봇입니다. 한국어와 중국어의 주요 질문 패턴, 이전 대화 주제, 실제 화면 효과 상태를 사용합니다. 자유로운 사실 질문의 답을 생성하거나 영상의 사물·옷 색·음성을 이해하지 않습니다. 답변에 사람 시청자처럼 닉네임이 붙지만 실제 외부 시청자의 메시지는 아닙니다.
