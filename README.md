# Douyin Live Studio

도우인 느낌의 중국어 라이브 방송 화면을 촬영하기 위한 독립형 웹 시연 도구입니다. 실제 도우인 서비스 연결, 방송 송출, 상품 주문, 결제는 하지 않습니다.

## 사용

`dist/index.html`을 브라우저에서 열면 바로 실행됩니다. 영상·사진을 선택하거나 카메라를 켜서 배경을 설정하세요. 자동 중국어 댓글, 수동 댓글, 팔로우, 하트, 장미 선물 효과를 사용할 수 있습니다. 방송 이름, 시청자 수, 좋아요 수와 댓글 속도를 조절할 수 있습니다. 직접 작성한 댓글은 한 줄에 하나씩 입력 후 적용하세요.

`촬영 모드 시작` 또는 `F`를 누르면 9:16 방송 화면만 표시합니다. 마우스를 움직이거나 화면을 터치하면 돌아가기 버튼이 잠시 나타납니다. `Esc`로 설정 화면으로 돌아갑니다. 운영체제나 브라우저의 화면 녹화 기능으로 촬영하세요. 이 앱이 직접 녹화 파일을 생성하지는 않습니다.

카메라는 HTTPS 배포 주소 또는 localhost에서 사용하세요. 카메라 권한은 직접 허용해야 합니다. 파일은 브라우저 메모리에서만 사용하고 서버로 업로드하지 않습니다. 재생 가능한 코덱은 브라우저에 따라 다릅니다. MP4(H.264) 또는 WebM을 권장합니다. 설정과 업로드 파일은 페이지를 새로 열면 초기화됩니다.

## 추가 효과

반응 효과 2종: 네온 폭죽(1), 무지개 파티(3). 설정 버튼 또는 방송 화면의 선물 메뉴에서도 실행할 수 있습니다. 약 6초 후 자동으로 사라집니다. 다른 효과를 누르면 새 효과로 교체합니다. (불꽃 효과는 성능 때문에 제거했습니다.)

얼굴 필터 3종: 왕눈이 토끼(4), 꿀꿀 돼지코(5), 콧수염 아저씨(6). 얼굴이 있는 사진, 영상 또는 카메라를 사용하면 얼굴 위치를 추적합니다. 배경이 없을 때는 캐릭터로 필터를 미리 보여줍니다. 같은 필터를 다시 누르면 해제됩니다. 0을 누르면 반응 효과와 얼굴 필터를 모두 끕니다. 글을 입력하는 동안 단축키는 작동하지 않습니다.

얼굴 추적은 Google MediaPipe Tasks Vision 1.1.0과 BlazeFace short-range 모델을 사용하며, 라이브러리와 모델을 사이트에 포함했습니다. 사진이나 영상 프레임은 브라우저의 Worker에서 처리하고 서버에 보내지 않습니다. 추적이 지원되지 않는 브라우저에서는 수동 위치 조절을 사용하세요. 여러 얼굴 중 가장 큰 얼굴 하나에 적용됩니다. 얼굴이 화면에서 사라지면 필터를 숨깁니다. 얼굴을 크게 움직이면 일시적으로 추적이 끊길 수 있습니다.

라이브러리: https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector/web_js

## 드립 치는 시청자

기본으로 시연형 시청자 댓글봇이 켜져 있습니다. 자동 댓글은 기본 약 2초 간격이며, 0.8–15초로 바꿀 수 있습니다. 간격은 약 ±18%씩 달라집니다. 자동 댓글의 기본 비중은 한국어 75% : 중국어 25%(3:1)이며, 한국어 비중을 0–100%로 조절할 수 있습니다. 한국어로 말을 걸면 주 답글과 후속 답글 모두 한국어로, 중국어로 말을 걸면 중국어로 답합니다. 짤을 붙일 때도 본문 언어를 유지합니다. 직접 등록한 문구는 작성한 언어 그대로 표시합니다.

한국어 문구를 늘리고 오래 사용하지 않은 문장을 먼저 고릅니다. 자동 한국어 댓글은 최근 100개의 문구를 피하며, 같은 필터를 오래 켜두면 다양한 일반 댓글도 섞어 반복을 줄입니다. 처음 화면을 열거나 시연을 다시 시작할 때도 한국어 3개와 중국어 1개로 시작합니다.

방송 화면의 채팅창에 질문하면 약 2–4초 후 입력한 언어로 농담을 답합니다. 가끔 다른 시청자가 후속 댓글을 붙입니다. 입력 중 표시가 나오며, 여러 질문은 순서대로 답하고 기존 자동 댓글은 답변하는 동안 잠시 기다립니다. 자동 댓글을 일시정지해도 질문 답변은 계속합니다. 시청자 반응 자체를 끄면 답변 대기열도 취소되고 원래의 샘플 댓글로 돌아갑니다.

댓글창은 마우스 휠·터치·키보드로 스크롤할 수 있고, 최근 500개를 이 페이지를 여는 동안 보관합니다. 과거 댓글을 읽는 동안 새 댓글이나 GIF가 도착해도 맨 아래로 끌고 가지 않습니다. ‘新评论’ 버튼에서 새 댓글 수를 확인하고 최신 댓글로 돌아갈 수 있습니다. 내가 새 댓글을 보내거나 시연을 다시 시작하면 최신 댓글을 따라갑니다.

‘내 댓글에 반응하기’는 기본으로 켜져 있습니다. 질문 외에 “ㅋㅋㅋ”, “노잼”, “인정”, “내 댓글 읽어줘”, “과제 하기 싫다” 같은 짧은 말에도 내용에 맞게 반응합니다. 내가 보낸 댓글에는 약 0.7–1.5초 후 시청자의 이모지 반응이 붙고, 답글에는 ‘回复 我’와 원문이 표시됩니다. 여러 댓글을 빠르게 보내도 각 답글의 원문이 맞게 연결됩니다. 이 기능을 끄거나 시연을 다시 시작하면 대기 중인 이모지·답글도 취소합니다. GIF 사용과 욕설 강도 설정은 내 댓글에 대한 답글에도 적용됩니다.

“내 이름은 승빈” 뒤 “내 이름 기억나?”처럼 이름을 기억하며, 필터 추천 뒤 “왜?”나 “더” 같은 후속 메시지도 이어갑니다. 필터·폭죽과 카메라 얼굴의 등장·이동·가까워짐에 관련된 드립을 붙입니다. 얼굴 관찰도 브라우저에서만 처리합니다. 새로 시작하면 대화 기억과 대기열을 지웁니다.

외부 언어모델을 호출하지 않는 규칙·문구 기반 시연용 댓글봇입니다. 한국어와 중국어의 주요 질문 패턴, 이전 대화 주제, 실제 화면 효과 상태를 사용합니다. 자유로운 사실 질문의 답을 생성하거나 영상의 사물·옷 색·음성을 이해하지 않습니다. 답변에 사람 시청자처럼 닉네임이 붙지만 실제 외부 시청자의 메시지는 아닙니다.

## 해외 밈과 GIF 댓글

2026년 10월 12일 확인한 자료를 바탕으로 SON, I’m crine, Black Cat Clapping, AI Rumpelstiltskin/Tiptoe, Cartman 학교 반응을 추가했습니다. SON은 2025년부터 이어지는 형식이며, Black Cat과 Tiptoe는 2026년 9–10월의 최근 사례입니다. Cartman은 예전 클립이 2026년 9월 다시 유행한 사례입니다. 출처와 확인일은 `dist/memes/SOURCES.md`에 있습니다. 자동으로 최신 밈을 검색하거나 갱신하는 기능은 아닙니다.

댓글 주제에 맞는 실제 GIF·이미지를 골라 함께 보냅니다. 학교·숙제 이야기는 Cartman, 춤·파티는 Tiptoe, 박수·칭찬은 Black Cat, 웃긴 얼굴 필터는 SON, 어이없거나 피곤한 반응은 I’m crine으로 연결합니다. 이미지 댓글은 기본 확률 35%이며, 자동 전송 간격은 최소 12초입니다. “SON 짤 보내줘”, “고양이 박수 GIF 보내줘”처럼 명시적으로 요청하면 전송 간격을 기다리지 않습니다. 화면의 ‘SON 짤 한번 보내보기’ 버튼도 있습니다.

짤을 누르면 확대하고 원본 출처를 열 수 있습니다. GIF·이미지 댓글 사용을 끄면 첨부가 모두 중단됩니다. 텍스트 밈과 욕설 설정은 독립적입니다. 욕설은 기본 적당히(일부 댓글에만 짧은 감탄사), 없음, 맵게를 선택할 수 있습니다. 욕설 없음은 강한 자막이 있는 Cartman GIF도 제외합니다. 외부 GIF 검색 API와 API 키는 사용하지 않고, 확인한 작은 밈팩을 사이트에서 직접 제공합니다.

## 실시간 방송 모드

정적 미리보기와 별도로, 관객 폰의 댓글·후원을 TV에 실시간으로 표시하는 서버가 포함되어 있습니다. 의존성은 없고 Node 22에서 바로 실행됩니다.

```bash
node server.cjs
# 또는
npm start
```

서버가 출력하는 주소 중:

- **Host** `http://127.0.0.1:4177/host?key=...` — 이 노트북에서 한 번 열어 호스트 쿠키를 받습니다. 이후 `/`의 `07 실시간 방송` 패널과 `/live` TV 스테이지를 사용할 수 있습니다.
- **Join** `http://<LAN-IP>:4177/j?c=...` — 관객 폰이 QR로 여는 주소입니다.
- QR은 TV 스테이지 시작 화면과 좌측 하단에 표시됩니다. 외부 QR API를 쓰지 않고 서버가 SVG로 생성합니다.

### 동작

- 관객은 닉네임만 입력하고 입장합니다. 기본 10명 선착순, 초과 인원은 대기열에 들어가고 자리가 나면 2초 안에 자동 승격됩니다.
- 댓글은 60자, 2초당 1개 수준으로 제한됩니다. 후원은 서버가 가격과 잔액을 검증하는 **시연용 가상 코인**이며 실제 결제는 없습니다.
- 좋아요는 2초 단위로 묶어서 집계합니다.
- 후원 효과는 `hearts`(爱心雨), `fireworks`(烟花盛典), `meteor`(流星雨), `lantern`(孔明灯), `party`(派对时间), `rainbow`(彩虹桥), `rocket`(火箭)로 구성됩니다. 랙이 심했던 `fire`(불꽃) 효과는 제거했습니다.
- 화려한 효과는 **모든 관객 합산 전역 큐**로 4초 간격, 최대 3개까지 대기합니다. 큐가 넘치면 후원 기록과 배너는 남지만 파티클 효과는 생략됩니다.
- 관객은 **미리 다운로드한 한정 밈팩**을 댓글로 보낼 수 있습니다. SON, I'm crine, Black Cat Clapping, Tiptoe, Fanum throws(GIF/IMG), This Is Fine, Surprised Pikachu, Crying Cat, Doge 10종이며 외부 GIF API는 쓰지 않습니다. 욕설이 포함된 Cartman 클립은 관객용 라이브 팩에서 제외했습니다.
- 밈을 추가하려면 `dist/memes/`에 파일을 넣고 `lib/memes.cjs`의 `MEMES`에 항목을 추가한 뒤 서버를 재시작하세요.
- SSE(Server-Sent Events)를 사용합니다. 영상은 서버로 전송하지 않고, TV 스테이지가 노트북 웹캠을 직접 렌더링한 뒤 HDMI로 TV에 출력합니다. Wi-Fi가 끊겨도 카메라 화면은 계속 나가고 댓글/후원만 재연결됩니다.
- 관객 페이지, TV 스테이지, 운영자 패널까지 앱 UI는 중국어입니다. 이 README만 한국어로 유지됩니다.

### TV 스테이지

1. `07 实时直播` 패널에서 **打开电视画面** 버튼을 클릭합니다.
2. TV 스테이지의 **开启摄像头** 버튼으로 웹캠을 허용하고, 필요하면 카메라/左右镜像을 선택합니다.
3. **开始直播** 버튼을 누르면 큰 QR이 작은 QR로 줄고 카메라가 전체 화면으로 나갑니다.
4. 브라우저 창을 HDMI 확장 디스플레이(TV)로 옮기고 전체 화면으로 띄웁니다.
5. 스마트 칠판에는 PPT를 그대로 띄웁니다. 앱은 PPT를 캡처하지 않습니다.

단축키: `Q` QR 숨김/표시, `H` 운영자 바, `F` 전체 화면, `S` 카메라 설정, `C` 댓글 지우기. 효과 테스트는 `1` 폭죽 · `2` 유성우 · `3` 파티 · `4` 하트비 · `5` 등불 · `6` 무지개 · `7` 로켓.

### 네트워크 주의

- 호스트는 반드시 `127.0.0.1`로 접속해야 카메라(`getUserMedia`)가 동작합니다. 관객은 LAN IP로 접속합니다.
- Windows 방화벽에서 Node의 개인 네트워크 인바운드를 허용하세요.
- 학교 Wi-Fi가 client isolation을 걸면 폰이 노트북에 접속하지 못합니다. 이때는 Windows 모바일 핫스팟을 켜고 폰을 여기에 연결하면 됩니다. 앱은 인터넷 없이 동작합니다.
- QR에 `localhost`가 들어가면 폰에서 접속할 수 없습니다. 서버가 자동으로 사설 LAN IP를 고르고, 잘못 고르면 환경 변수로 지정하세요.
  - PowerShell: `$env:LAN_IP="192.168.0.12"; node server.cjs`
  - cmd: `set LAN_IP=192.168.0.12 && node server.cjs`
  - Git Bash: `LAN_IP=192.168.0.12 node server.cjs`
- `.live-config.json`에는 호스트 키와 방 코드가 저장됩니다. Git에 커밋하지 마세요.
- `.openai/hosting.json`의 정적 호스팅에는 SSE 서버가 포함되지 않습니다. 실시간 모드는 노트북에서 `node server.cjs`로 실행하세요.

### 현장 체크

- 노트북은 `127.0.0.1`로 호스트 페이지를 열고, TV는 **HDMI 확장 디스플레이**로 연결하세요. TV에는 `/live` 창만 전체 화면으로 보냅니다.
- 스마트 칠판에는 PPT를 그대로 띄웁니다. 앱은 슬라이드를 캡처하지 않습니다.
- 노트북 덮개를 닫으면 내장 웹캠이 꺼질 수 있습니다. 외장 USB 웹캠을 쓰거나 덮개를 열어두세요.
- 카메라 렌즈가 발표자를 향하게 두고, TV 화면이 카메라에 잡히지 않게 배치하세요.
- TV의 절전/화면보호기/알림을 끄고, 가능하면 ‘게임/PC’ 화질 모드로 두세요.
- 관객 10명이 실제로 접속하는지 수업 전에 리허설하세요. Wi-Fi가 막히면 노트북 핫스팟으로 전환합니다.
- 영상과 음성은 서버로 전송하지 않습니다. 서버를 거치는 것은 댓글·좋아요·후원 JSON뿐입니다.
